# Reflection

## 1. HTTP Request Path

When I open my site in a browser, the request starts with the browser looking up `omaimasharhan.github.io` to find the server’s IP. It then connects to GitHub’s server, requests the files like `index.html` and CSS, and the browser receives them and displays the website.

## 2. Docker vs GitHub Pages

Docker provides a full environment where I can run programs with all the dependencies and system settings I need. GitHub Pages, on the other hand, only serves static files like HTML, CSS, and JavaScript, so it cannot run backend code or applications.

---

## 3. flex-direction: row vs flex-direction: column
The difference between using row and column is the direction in which items are placed inside the flex container. flex-direction: row positions items horizontally from left to right, while flex-direction: column places items vertiaclly from top to bottom.

## 4. Relative Units 

Relative units are important in responsive design becuase they are more flexible and adjust based on the screen size or surrounding elements, unlike fixed pixel values which stay the same size and may not display well on different devices.
